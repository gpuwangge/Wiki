# 二进制加法减法
计算机不会只对一个二进制数进行操作，而是对一组二进制数进行操作。  
8个二进制为一个字节。  
字（word）：在不同的计算机里有不同的定义，可能是16、32位。  
一个8位的字型可以表示256个可能的值。  

计算机里有符号数的表示法：
- 符号及值表示法：最高位如果是0表示整数，最高位是1表示负数。缺点是10000000和00000000都可以表示0。
整数算数不用这个表示法（因为加法和减法需要分别的加法器和减法器）；但浮点算术使用这个表示法。  
- 补码（2's complement）：可以将减法运算转换为对减数的补码的加法运算。  
二进制数中，求补码的方法是取反并加一。  
二进制数n的补码也可以用 2^n-n求。但不如取反加一好用。  

举例：  
+5=00000101，其负数二进制补码为11111011。  
+7=00000111，其负数二进制补码为11111001。  
现在要计算7-5的话，用7和5的负数补码相加：  
00000111+11111011=1,0000,0010-2（忽略最左边的进位1）  
要计算5-7的话，用5和7的负数补码相加：  
00000101+11111001=11111110，这时候可以看到得到一个负数，计算机就知道这是-2（以补码的二进制形式存在）。  
为了人类读个数，11111110取反加一$-00000010-，然后考虑上符号才能得到-2。  
在现代通用计算机中，只要涉及CPU寄存器，算术逻辑单元（ALU）内部的所有符号整数运算与存储，负数默认且几乎100%以补码（Two's Complement）形式存在。  
正整数在计算机中同样是以补码形式存在的。但它的特殊之处在于（这个是定义）：正数的补码＝它本身的纯二进制表示，所以通常被直观地称为“二进制原值”，导致很多人误以为“只有负数才叫补码”。

用补码系统的好处是：  
- 零是唯一的
- 只需要有加器，就可以同时实现加法和减法

# 二进制乘法
- 移位加法：无符号正数二进制乘法，跟十进制乘法类似。注意每次得到一个部分积都立刻累加。
- 快速乘法：因为移位加法速度很慢，采取优化。
比如: 10P=2x(2x2xp+p)，左移两次，加一次，再左移一次。  
9p=2x2x2xp+p, 三次左移，加一次。  
- 查表法(look-up table)：用空间换时间。

# 二进制除法
二进制和十进制的除法是一样的。  
除法是通过被除数不断地减去除数直到结果为0或小于除数来实现的。减去除数的次数称作商。最后一次减去的差称作余数。  

# 浮点数(Floating-point number)
浮点数是数学里的实数，是所有有理数和无理数的集合。  
浮点数的意思是小数点的位置不固定。  
浮点运算的结果一般是不确定的。一块芯片上的浮点计算结果也许在另一个芯片上就不一样。  
比如ARM和INTEL的CPU生产商不同，指令集不同，浮点数的存储方式不一样，结果也会有小的区别。  

科学计数法：可以表示很小或很大的数。  
- 十进制浮点数可以表示为：尾数x10^指数。  
- 二进制浮点数可以表示为：尾数x2^指数。  

IEEE 754提供三种浮点数  
- 32位单精度浮点数  
- 64位双精度浮点数  
- 128位四精度浮点数  

整数操作是精确、可重复的。  
浮点数操作是不精确的。  
IEEE要求加减乘除运算结果能够精确计算，并用向偶数舍入的方法将结果舍入为最近的浮点数。  
舍入就会产生误差。
